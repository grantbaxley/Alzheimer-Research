## The approved EEG analysis: no detectable direction at the dementia stage

`early-warning-direction-test` asks which way an early-warning signal should point: longer
timescales and more variability (critical slowing down), or shorter (lost neurons). First pass on
OpenNeuro ds004504 (CC0; 36 Alzheimer's, 23 frontotemporal dementia, 29 controls; resting, eyes
closed), using `scripts/eeg_direction_test_2026_11_13.py`. Recordings stayed outside the
repository; only code and group-level statistics are kept.

| Measure (Alzheimer's minus controls, n=65) | Unadjusted d | Adjusted for age, sex, peak frequency |
|---|---|---|
| Peak frequency, 4-13 Hz (EEG slowing) | -0.76 [-1.52, -0.23] | - |
| Broadband autocorrelation window | -0.06 [-0.61, +0.42] | -0.14 [-0.92, +0.42] |
| Envelope persistence | +0.01 [-0.44, +1.04] | +0.17 [-0.26, +0.94] |
| Envelope variability | -0.02 [-0.42, +0.67] | +0.07 [-0.44, +0.93] |

- **The method works:** it recovers the well-known slowing of the EEG in Alzheimer's (and in
  frontotemporal dementia, d = -0.74).
- **No direction shows:** all three resilience-type measures fall under the pre-stated 0.2
  threshold after adjustment. Neither the critical-slowing-down sign nor the opposite appears.
- **This is not proof of no effect:** with 65 people the intervals run to roughly +/-0.9, so a
  moderate effect either way could be hidden.
- **Limits:** symptomatic patients at one hospital, so nothing here speaks to the years before
  symptoms; the broadband window is dominated by activity below 2 Hz. One sensitivity check is
  declared in the idea's next step; I did not run extra variants after seeing the result.

Registry: the dataset is recorded as `openneuro-ds004504` (grade B). Its licence was read from the
dataset's own description file (CC0, version 1.0.9); there is no separate licence file.

## Revisited: circadian-period-enrichment -> PARKED

The idea used a person's intrinsic body-clock period, measured in cultured skin cells, to enrich
trials. Reading the anchor paper (PNAS 2026, 10.1073/pnas.2527236123; 135 people, 119 followed):
the progression result (longest-period fifth, HR 4.41, 95% CI 1.52-12.83) did **not** adjust for
plasma p-tau217, amyloid status or baseline severity, and there is no replication cohort. So
"independent of pathology" is not shown. The marker needs a skin biopsy and weeks of cell culture
and has no published repeatability. 2026 data also lean against a causal body-clock story
(chronotype null for Alzheimer's in 443,906 people, 10.1177/13872877261498357; rest-activity links
to p-tau217 not surviving correction, 10.1007/s11357-026-02645-6 - both as reported). The idea
reopens only if the authors report the adjusted model or someone replicates it.
